# Pica Typewriter

Uma máquina de escrever no navegador: fonte de datilografia, fita gasta, som de teclas, carro que anda, páginas A4/Carta e exportação para .txt, .md, imagem e PDF.

**Use agora:** https://bruno475beep.github.io/pica-typewriter/

Fitas *Worn ribbon*, *Very worn ribbon* e *Clean*, e duas opções que se combinam com qualquer fita: *Aged paper* (papel amarelado, manchas, poeira e dobras de documento antigo) e *Coffee rings* (marcas aleatórias de xícara de café; marque de novo para sortear outras).

Tudo roda num único arquivo `index.html`, sem servidor e sem instalação — pode baixá-lo e abrir offline. O texto fica guardado só no seu navegador.

Atalhos: Ctrl+B negrito · Ctrl+I itálico · Ctrl+U sublinhado · Ctrl+Z desfazer.

A primeira versão, sem os efeitos novos, continua em https://bruno475beep.github.io/pica-typewriter/v1/
